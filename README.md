# SmartPrice 🇧🇬 — Сподели реални цени, касови бележки и места

Мобилно приложение за **iOS, Android и Web** (изградено с **React Native Expo + TypeScript + Supabase + Stripe**), в което общността споделя:
- 🟢 **Топ Находки (Струва си):** евтини цени, честни ресторанти, проверени хотели/Airbnb/Booking нощувки, реални промоции в супермаркети и коректни услуги.
- 🔴 **Червени Флагове (Къде да НЕ се ходи и пазарува):** скрити такси („куверт/сервиз“), спекулативни цени, „шринкфлация“, подвеждащи обяви в Booking/Airbnb и лошо качество.
- 🧾 **AI Скенер на Касови Бележки (OCR):** автоматично извличане на търговец, ЕИК, дата, артикули и сума от снимка на фискален бон.
- 💳 **Монетизация чрез Дарения през Stripe + Периодично Напомняне:** ако потребителят все още не е дарил (`isSupporter = false`), приложението периодично (на всеки 3 интеракции или по таймер) показва ненатрапчив диалог за подкрепа с избор на суми (5 лв., 10 лв., 25 лв. или произволна сума). След дарение се отключва златна значка **„Пазител на Общността“** и напомнянията спират.

---

## Стартиране на проекта

```bash
# 1. Инсталиране на зависимостите (вече са инсталирани)
npm install

# 2. Стартиране на Expo сървъра (за iPhone Expo Go, Android или Web)
npx expo start
```

- Натисни **`i`** за iOS Simulator
- Натисни **`a`** за Android Emulator
- Натисни **`w`** за Web браузър
- Сканирай QR кода с **Expo Go** на своя iPhone или Android телефон.
